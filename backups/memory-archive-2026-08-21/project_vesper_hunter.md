Vesper (long-range sharpshooter: Sunspike Carbine hitscan, Deadeye Focus scoped headshot ramp, Grapple Hook, Pinning Round slow+mark, Starfall Sight piercing ultimate) is **code-complete in Redwater Canyon** as of 2026-07-05. 11 scripts: `RS.Hunters.Vesper.Config.{Manifest,VesperConfig}`, `SSS.Hunters.VesperServer.{SunspikeModule,SunspikeDamageService,GrappleHookService,PinningRoundService,StarfallSightModule}`, `SPS.Vesper.{SunspikeClient,VesperScopeController,VesperHunterGuiClient}`, plus shared `RS.Hunters.Shared.HunterStatusEffects` (built shared from day one because [[project-bram-hunter]] also needs slows — its second consumer). All vault .md files + graph are synced. Design source: `vesper_implementation_guide.md`.

**Why:** User asked to implement her from the guide; all [ASSUMPTION] balance values used verbatim (ADSFOV 35, scoped walk 6, grapple TravelTime 0.35s, pinning cd 12s) — they need a playtest pass.

**2026-07-06 tuning pass (user-requested):** Pinning Round changed from a lobbed **ballistic arc** to a **straight-line shot** — `PinningRoundService._simulate` no longer applies gravity; `ThrowSpeed 90→250`, `MaxFlightTime 3→2s` (~500 stud reach). Still utility-only (slow+mark on landing, no direct damage). Scope now **reduces mouse look sensitivity** — `VesperConfig.Scope.ScopedSensitivityMultiplier = 0.4`; `VesperScopeController` captures `UserInputService.MouseDeltaSensitivity` on scope-in, multiplies, restores on scope-out (settings menu owns the base value). Scope now **auto-drops on reload** via a new `ReloadStarted` client bindable (added to Vesper Manifest ClientEvents; `SunspikeClient.startReload` fires it, `VesperScopeController` listens → `setScoped(false)`).
