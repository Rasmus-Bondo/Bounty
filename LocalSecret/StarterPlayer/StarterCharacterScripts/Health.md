# Health

Empty override of Roblox's default `Health` script, which disables automatic health regeneration.

## What it does
1. Contains only a comment. Because a script named `Health` in StarterCharacterScripts replaces the engine's default regen script, characters never regenerate; healing comes from encounter breaks, potions and boons instead.
