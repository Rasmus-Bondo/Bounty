# Plan 01-01: RemoteEvent Consolidation + Per-Player Rate Limiting

<objective>
Consolidate all RemoteEvents into a centralized Events folder in ReplicatedStorage, and fix the shared cooldown bug in GunServer by implementing per-player rate limiting.
</objective>

<important>
## MCP Tool Requirement

ALL changes to Roblox Studio instances MUST use the Roblox Studio MCP tools. NEVER write .lua files to the filesystem. The code lives inside Roblox Studio's data model.

Key tools:
- `mcp__robloxstudio__create_object` — create instances (ModuleScript, Folder, RemoteEvent)
- `mcp__robloxstudio__set_script_source` — write Luau code into scripts
- `mcp__robloxstudio__get_script_source` — read existing scripts
- `mcp__robloxstudio__get_project_structure` — explore hierarchy
- `mcp__robloxstudio__delete_object` — remove instances
- `mcp__robloxstudio__set_property` — set properties

Instance paths use dot notation: `game.ServerScriptService.RoundSystem.Modules.Config`
</important>

<tasks>

<task id="01-01-01" type="code" autonomous="true">
<name>Create Events folder and move RemoteEvents</name>
<read_first>
- Use `mcp__robloxstudio__get_project_structure` path="game.ReplicatedStorage" to see current layout
- Use `mcp__robloxstudio__get_script_source` for game.ServerStorage.BanditGun.GunServer to see current remote references
</read_first>
<action>
1. Create a Folder named "Events" under ReplicatedStorage:
   `mcp__robloxstudio__create_object` className="Folder", name="Events", parent="game.ReplicatedStorage"

2. Move GunRemote into Events folder by creating a new RemoteEvent inside Events and deleting the old one:
   `mcp__robloxstudio__create_object` className="RemoteEvent", name="GunRemote", parent="game.ReplicatedStorage.Events"
   `mcp__robloxstudio__delete_object` instancePath="game.ReplicatedStorage.GunRemote"

3. Move EliminatePlayer into Events folder:
   `mcp__robloxstudio__create_object` className="BindableEvent", name="EliminatePlayer", parent="game.ReplicatedStorage.Events"
   `mcp__robloxstudio__delete_object` instancePath="game.ReplicatedStorage.EliminatePlayer"

4. Create CombatEvents ModuleScript in Events folder for centralized access:
   `mcp__robloxstudio__create_object` className="ModuleScript", name="CombatEvents", parent="game.ReplicatedStorage.Events"

5. Set CombatEvents source:
   `mcp__robloxstudio__set_script_source` with this code:
```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Events = ReplicatedStorage:WaitForChild("Events")

local CombatEvents = {}

CombatEvents.GunRemote = Events:WaitForChild("GunRemote")
CombatEvents.EliminatePlayer = Events:WaitForChild("EliminatePlayer")

return CombatEvents
```
</action>
<acceptance_criteria>
- `mcp__robloxstudio__get_project_structure` path="game.ReplicatedStorage.Events" shows Folder with GunRemote (RemoteEvent), EliminatePlayer (BindableEvent), CombatEvents (ModuleScript)
- `mcp__robloxstudio__get_instance_children` path="game.ReplicatedStorage" does NOT show GunRemote or EliminatePlayer at root level
- `mcp__robloxstudio__get_script_source` for game.ReplicatedStorage.Events.CombatEvents contains "Events:WaitForChild"
</acceptance_criteria>
</task>
