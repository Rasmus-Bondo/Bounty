# Plan 01-03: UI Cleanup + Architecture Consolidation

<objective>
Remove Townsfolk UI elements from GameplayGui, update the role reveal to show deathmatch messaging, and consolidate standalone scripts into the RoundSystem architecture as the central GameManager.
</objective>

<important>
## MCP Tool Requirement

ALL changes to Roblox Studio instances MUST use the Roblox Studio MCP tools. NEVER write .lua files to the filesystem.

Key tools:
- `mcp__robloxstudio__set_script_source` — write Luau code into scripts
- `mcp__robloxstudio__get_script_source` — read existing scripts
- `mcp__robloxstudio__get_project_structure` — explore hierarchy
- `mcp__robloxstudio__create_object` — create new instances
- `mcp__robloxstudio__delete_object` — remove instances
- `mcp__robloxstudio__set_property` — set instance properties
</important>

<task id="01-03-02" type="code" autonomous="true">
<name>Update RoleRevealClient for deathmatch mode</name>
<read_first>
- `mcp__robloxstudio__get_script_source` for game.StarterGui.GameplayGui.Canvas.RoleRevealClient
</read_first>
<action>
Update RoleRevealClient via `mcp__robloxstudio__set_script_source` instancePath="game.StarterGui.GameplayGui.Canvas.RoleRevealClient":
```lua
local Players = game:GetService("Players")
local player = Players.LocalPlayer

local canvas = script.Parent

local banditText = canvas:WaitForChild("BanditText")
local banditShadow = canvas:WaitForChild("BanditTextShadow")

local SHOW_TIME = 3

local function hideAll()
	banditText.Visible = false
	banditShadow.Visible = false
end

local function showRole(role)
	hideAll()

	if role == "Bandit" then
		banditText.Text = "FIGHT!"
		banditShadow.Text = "FIGHT!"
		banditText.Visible = true
		banditShadow.Visible = true
	end

	task.wait(SHOW_TIME)
	hideAll()
end

player:GetAttributeChangedSignal("Role"):Connect(function()
	local role = player:GetAttribute("Role")
	if role then
		showRole(role)
	end
end)

hideAll()
```
Key changes: Removed all Townsfolk text references. Changed "BANDIT" display to "FIGHT!" for deathmatch mode. Reduced SHOW_TIME from 4 to 3.
</action>
<acceptance_criteria>

- RoleRevealClient contains 'banditText.Text = "FIGHT!"'
</acceptance_criteria>
</task>

<task id="01-03-04" type="code" autonomous="true">
<name>Convert standalone scripts to ModuleScripts under RoundSystem</name>
<read_first>
- `mcp__robloxstudio__get_script_source` for game.ServerScriptService.RagdollOnDeath
- `mcp__robloxstudio__get_script_source` for game.ServerScriptService.PlayerCollisionGroup
- `mcp__robloxstudio__get_script_source` for game.ServerScriptService.leaderstat
- `mcp__robloxstudio__get_script_source` for game.ServerScriptService.Footstep
- `mcp__robloxstudio__get_script_source` for game.ServerScriptService.ForceDefaultR15Animate
</read_first>
<action>
For each standalone script, create a ModuleScript equivalent under RoundSystem.Modules and disable the original:

1. For each script (RagdollOnDeath, PlayerCollisionGroup, leaderstat, Footstep, ForceDefaultR15Animate):
   a. Read its source with `mcp__robloxstudio__get_script_source`
   b. Create a ModuleScript under game.ServerScriptService.RoundSystem.Modules with a service-style name:
      - RagdollOnDeath -> RagdollService
      - PlayerCollisionGroup -> CollisionService
      - leaderstat -> LeaderstatService
      - Footstep -> FootstepService
      - ForceDefaultR15Animate -> AnimateService
   c. Wrap the script's functionality in a module with an Initialize() function
   d. Disable the original script: `mcp__robloxstudio__set_property` instancePath="game.ServerScriptService.{name}" propertyName="Enabled" propertyValue=false

2. Update RoundSystem.MainServer to require and initialize these new service modules:
   Read current MainServer source, then update via `mcp__robloxstudio__set_script_source`:
   ```lua
   local RoundController = require(script.Parent.Modules.RoundController)
   local RagdollService = require(script.Parent.Modules.RagdollService)
   local CollisionService = require(script.Parent.Modules.CollisionService)
   local LeaderstatService = require(script.Parent.Modules.LeaderstatService)
   local FootstepService = require(script.Parent.Modules.FootstepService)
   local AnimateService = require(script.Parent.Modules.AnimateService)

   -- Initialize utility services
   RagdollService.Initialize()
   CollisionService.Initialize()
   LeaderstatService.Initialize()
   FootstepService.Initialize()
   AnimateService.Initialize()

   -- Start round system
   RoundController.connectEvents()
   RoundController.connectPlayers()
   RoundController.run()
   ```

Each module follows the pattern:
```lua
local ServiceName = {}

function ServiceName.Initialize()
    -- Original script logic here, connected to events
end

return ServiceName
```
</action>
