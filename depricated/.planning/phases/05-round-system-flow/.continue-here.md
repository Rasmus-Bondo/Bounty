<decisions_made>

1. **LobbyGui button positioning via set_property**: Original create_object calls set Size/Position but they came through as 0,0. Had to use set_property after creation to fix.

2. **Role attribute in LobbyService.optIn**: FirstPersonCamera script checks player:GetAttribute("Role") to enable first-person view. Was only set in RoundController.hookCharacter (fires on character spawn), but mid-match joins use existing character so hookCharacter doesn't fire. Solution: set Role immediately in LobbyService.optIn when round is active.

3. **InvulnService in LobbyService.optIn**: Similar issue - InvulnService.applyInvulnerability was only called from hookCharacter. Mid-match joins need spawn protection but hookCharacter doesn't fire. Solution: call InvulnService.applyInvulnerability directly from LobbyService.optIn.

4. **RequestStats handler merges data**: StatMenuScript expects fields like SessionKills, SessionDeaths, TimeAlive, TimeDead. DataService.getPlayerData only returns persistent data (Cash, Level, XP, LifetimeKills, LifetimeDeaths, TotalPlaytime). Session data is in separate DataService.getSessionData. ProgressionService RequestStats handler now merges both before sending to client.

5. **Stats button PC support**: InputController only wired stats button when `isMobile` was true. Button was visible on PC but did nothing. Now wired for both PC and mobile users.

</decisions_made>
