  <name>Task 1: Add RoundTimeLeft attribute to RoundController fight loop</name>
  <files>
    game.ServerScriptService.RoundSystem.Modules.RoundController
  </files>
  <read_first>
    game.ServerScriptService.RoundSystem.Modules.RoundController,
    game.StarterGui.LobbyGui.LobbyScript
  </read_first>
  <action>
In RoundController's fight phase countdown loop (the section that counts down from Config.ROUND_TIME), add this line inside the countdown loop body:
```lua
workspace:SetAttribute("RoundTimeLeft", remainingTime)
```
where `remainingTime` is the loop variable tracking seconds left in the round.

At the start of the intermission phase (after fight ends), reset:
```lua
workspace:SetAttribute("RoundTimeLeft", 0)
```

At the start of the waiting phase, also reset:
```lua
workspace:SetAttribute("RoundTimeLeft", 0)
```

This enables the LobbyScript (Plan 03) to read and display the round timer via `workspace:GetAttribute("RoundTimeLeft")`.
  </action>
  <verify>
    <automated>
    In Roblox Studio F5 (Play Solo):
    - During active round, running `workspace:GetAttribute("RoundTimeLeft")` in command bar returns a number > 0
    - During intermission/waiting, returns 0
    </automated>
  </verify>
  <acceptance_criteria>
    - RoundController fight loop sets workspace:SetAttribute("RoundTimeLeft", remainingTime) each second
    - RoundController sets workspace:SetAttribute("RoundTimeLeft", 0) when round ends
    - RoundController sets workspace:SetAttribute("RoundTimeLeft", 0) during waiting phase
  </acceptance_criteria>
  <done>RoundTimeLeft attribute updates each second during active round, resets to 0 during intermission/waiting. Lobby timer display now has data source.</done>
