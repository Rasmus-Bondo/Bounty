**Server-side caches:**
- `local playerDataCache = {}` -- [userId] = data table (loaded from DataStore or defaults)
- `local sessionTracker = {}` -- [userId] = { Kills=0, Deaths=0, TimeAlive=0, TimeDead=0, JoinTime=os.clock(), LastAliveTime=os.clock(), IsAlive=false }
- `local savedPlayers = {}` -- [userId] = true, prevents double-save in BindToClose (per Pitfall 2)
- `local timeTrackingConnections = {}` -- [userId] = { diedConnection, spawnedConnection, heartbeatConnection }

**Functions to implement:**

1. `safeGet(key)` -- pcall-wrapped GetAsync with retry loop (MAX_RETRIES attempts), exponential backoff (attempt * 2 seconds wait). Returns data or nil. Warns on failure after all retries.

2. `safeSave(player)` -- pcall-wrapped SetAsync. Gets data from playerDataCache[player.UserId]. Updates TotalPlaytime by adding `os.clock() - sessionTracker[userId].JoinTime` delta before save. JSONEncode the data table before SetAsync. Returns success boolean. Warns on failure.

3. `DataService.loadPlayerData(player)` -- Called on PlayerAdded. Uses safeGet with key `tostring(player.UserId)`. If data returned, JSONDecode if string type, then merge with DEFAULT_DATA (handle schema additions -- for each key in DEFAULT_DATA, use loaded value if present, else default). If nil returned (new player, per Pitfall 3), deep-copy DEFAULT_DATA. Store in playerDataCache[player.UserId]. Initialize sessionTracker[player.UserId] = { Kills=0, Deaths=0, TimeAlive=0, TimeDead=0, JoinTime=os.clock(), LastAliveTime=os.clock(), IsAlive=false }. Set initial player attributes: `player:SetAttribute("SessionKills", 0)` and `player:SetAttribute("SessionDeaths", 0)`. Return the data table.

4. `DataService.getPlayerData(player)` -- Returns playerDataCache[player.UserId] or nil.

5. `DataService.getSessionData(player)` -- Returns sessionTracker[player.UserId] or nil.

6. `DataService.incrementSessionStat(player, statName, amount)` -- Increments sessionTracker[userId][statName] by amount. For "Kills" also increments playerDataCache[userId].LifetimeKills. For "Deaths" also increments playerDataCache[userId].LifetimeDeaths. **CRITICAL: Also set player attributes for client-readable scoreboard data:** `player:SetAttribute("Session" .. statName, sessionTracker[userId][statName])` -- this makes SessionKills and SessionDeaths readable by any client for the scoreboard (Plan 03 depends on this).

7. `DataService.updateLeaderstats(player)` -- Finds player:FindFirstChild("leaderstats"), sets Cash.Value, Level.Value, XP.Value from playerDataCache.

8. `setupTimeTracking(player)` -- **NEW: Tracks TimeAlive and TimeDead per D-02.** Called after loadPlayerData. Connects to player.CharacterAdded to detect spawns and Humanoid.Died to detect deaths. Implementation:

```lua
local function setupTimeTracking(player)
    local userId = player.UserId
    local connections = {}

    -- Heartbeat connection to accumulate time every frame
    connections.heartbeat = RunService.Heartbeat:Connect(function(dt)
        local session = sessionTracker[userId]
        if not session then return end
        if session.IsAlive then
            session.TimeAlive = session.TimeAlive + dt
        else
            session.TimeDead = session.TimeDead + dt
        end
    end)

    -- CharacterAdded: player just spawned, mark alive
    connections.characterAdded = player.CharacterAdded:Connect(function(character)
        local session = sessionTracker[userId]
        if not session then return end
        session.IsAlive = true

        -- Listen for death
        local humanoid = character:WaitForChild("Humanoid", 10)
        if humanoid then
            if connections.died then connections.died:Disconnect() end
            connections.died = humanoid.Died:Connect(function()
                local s = sessionTracker[userId]
                if s then
                    s.IsAlive = false
                end
            end)
        end
    end)

    -- If character already exists (race condition), set alive
    if player.Character then
        local humanoid = player.Character:FindFirstChild("Humanoid")
        if humanoid and humanoid.Health > 0 then
            local session = sessionTracker[userId]
            if session then session.IsAlive = true end
        end
    end

    timeTrackingConnections[userId] = connections
end
```

9. `cleanupTimeTracking(player)` -- Disconnects all time tracking connections for player. Called on PlayerRemoving.

```lua
local function cleanupTimeTracking(player)
    local connections = timeTrackingConnections[player.UserId]
    if connections then
        if connections.heartbeat then connections.heartbeat:Disconnect() end
        if connections.characterAdded then connections.characterAdded:Disconnect() end
        if connections.died then connections.died:Disconnect() end
    end
    timeTrackingConnections[player.UserId] = nil
end
```

10. `DataService.Initialize()` -- Sets up:
   - PlayerAdded connection: calls loadPlayerData, then updateLeaderstats (waits for leaderstats to exist via WaitForChild with 10s timeout since LeaderstatService creates them), then calls setupTimeTracking(player)
   - PlayerRemoving connection: calls cleanupTimeTracking(player), then safeSave(player), marks savedPlayers[userId]=true, cleans up playerDataCache[userId] and sessionTracker[userId]
   - Auto-save loop: `task.spawn(function() while true do task.wait(AUTO_SAVE_INTERVAL) for _, player in Players:GetPlayers() do task.spawn(function() safeSave(player) end) end end end)`
   - BindToClose (per D-05): If not RunService:IsStudio(), parallel-save all players not in savedPlayers using task.spawn per player, wait for all to complete or 25s timeout. Log completion: `print("[DataService] BindToClose: saved N players in Xs")`. If IsStudio, task.wait(1) and return.
   - RequestStats RemoteEvent handler: When client fires RequestStats, respond with StatsResponse containing session data + lifetime data from cache.

```lua
requestStatsEvent.OnServerEvent:Connect(function(player)
    local data = playerDataCache[player.UserId]
    local session = sessionTracker[player.UserId]
    if data and session then
        local now = os.clock()
        local statsPayload = {
            -- Progression (also in leaderstats but sent for completeness)
            Cash = data.Cash,
            Level = data.Level,
            XP = data.XP,
            XPToNextLevel = 1000 - (data.XP % 1000),
            -- Session
            SessionKills = session.Kills,
            SessionDeaths = session.Deaths,
            TimeAlive = session.TimeAlive,
            TimeDead = session.TimeDead,
            -- Lifetime
            LifetimeKills = data.LifetimeKills,
            LifetimeDeaths = data.LifetimeDeaths,
            TotalPlaytime = data.TotalPlaytime + (now - session.JoinTime),
        }
        statsResponseEvent:FireClient(player, statsPayload)
    end
end)
```
