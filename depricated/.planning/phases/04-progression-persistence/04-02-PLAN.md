Create a new ModuleScript `ProgressionService` under game.ServerScriptService.RoundSystem.Modules.

**Tunable constants at top of module** (per D-13):
```lua
local XP_PER_KILL = 100          -- D-07
local CASH_PER_KILL = 10         -- D-08: $10
local ROUND_BONUS_XP = 50        -- D-09
local ROUND_BONUS_CASH = 5       -- D-09: $5
local TIME_REWARD_XP = 25        -- D-10
local TIME_REWARD_CASH = 3       -- D-10: $3 (rounded from $2.50 to avoid float precision, per Pitfall 7)
local TIME_REWARD_INTERVAL = 120 -- D-10: 2 minutes in seconds
local XP_PER_LEVEL = 1000        -- D-11: Linear progression
```

**Required services:**
```lua
local Players = game:GetService("Players")
local DataService -- set in Initialize via require
local levelUpEvent -- RemoteEvent reference, set in Initialize
```

**Functions:**

1. `ProgressionService.awardKill(player)` -- Called when player gets a kill.
   - Get data via DataService.getPlayerData(player), return if nil
   - `data.XP = data.XP + XP_PER_KILL`
   - `data.Cash = data.Cash + CASH_PER_KILL`
   - `DataService.incrementSessionStat(player, "Kills", 1)` (increments session + lifetime)
   - Check level-up: `local newLevel = math.floor(data.XP / XP_PER_LEVEL) + 1`
   - If newLevel > data.Level: `data.Level = newLevel`, fire `levelUpEvent:FireClient(player, newLevel)`
   - Call `DataService.updateLeaderstats(player)`
   - Print: `"[Progression] " .. player.Name .. " earned " .. XP_PER_KILL .. " XP + $" .. CASH_PER_KILL .. " for kill"`

2. `ProgressionService.awardDeath(player)` -- Called when player dies.
   - `DataService.incrementSessionStat(player, "Deaths", 1)`

3. `ProgressionService.awardRoundCompletion(player)` -- Called at round end for all active players.
   - Get data via DataService.getPlayerData(player), return if nil
   - `data.XP = data.XP + ROUND_BONUS_XP`
   - `data.Cash = data.Cash + ROUND_BONUS_CASH`
   - Check level-up (same logic as awardKill)
   - Call `DataService.updateLeaderstats(player)`
   - Print round completion award log

4. `checkLevelUp(player, data)` -- Internal helper to avoid duplicating level-up logic.
   - `local newLevel = math.floor(data.XP / XP_PER_LEVEL) + 1`
   - If newLevel > data.Level: update, fire event, print level-up message
   - Return newLevel

5. **Time-based reward loop** in Initialize:
   ```lua
   task.spawn(function()
       while true do
           task.wait(TIME_REWARD_INTERVAL)
           for _, player in Players:GetPlayers() do
               -- Only award if player is alive (has a character with Humanoid Health > 0)
               local character = player.Character
               local humanoid = character and character:FindFirstChild("Humanoid")
               if humanoid and humanoid.Health > 0 then
                   local data = DataService.getPlayerData(player)
                   if data then
                       data.XP = data.XP + TIME_REWARD_XP
                       data.Cash = data.Cash + TIME_REWARD_CASH
                       checkLevelUp(player, data)
                       DataService.updateLeaderstats(player)
                   end
               end
           end
       end
   end)
   ```
   Note: D-10 says "while player is alive and round is active." Round-active check will be wired in Phase 5 when the round system is built. For now, award whenever alive. Add a TODO comment: `-- TODO Phase 5: Also check if round is active before awarding time rewards`. **Ensure Phase 5 planning addresses this -- time rewards MUST be gated by round-active state.**

6. `ProgressionService.Initialize()` -- Sets up:
   - Require DataService: `DataService = require(script.Parent:WaitForChild("DataService"))`
   - Get LevelUp event: `levelUpEvent = game.ReplicatedStorage.Events.ProgressionEvents:WaitForChild("LevelUp")`
   - Start time-based reward loop
   - Print "[ProgressionService] Initialized"
