Add fire effect state and functions to existing ZoneService:

```luau
-- Fire effect state (add to existing ZoneService state)
local fireEffects = {}

-- Create fire particle system  
function createFireEffects(zoneBounds)
    -- Clear existing fire
    for _, effect in pairs(fireEffects) do
        effect:Destroy()
    end
    fireEffects = {}
    
    -- Create fire particles at zone boundaries
    -- West boundary fire line
    local westFire = Instance.new("Part")
    westFire.Name = "ZoneFire_West"  
    westFire.Size = Vector3.new(1, 5, 200)  -- Thin vertical fire wall
    westFire.Position = Vector3.new(zoneBounds.westX, Config.CANYON_CENTER_Y, Config.CANYON_CENTER_Z)
    westFire.Anchored = true
    westFire.CanCollide = false
    westFire.Transparency = 1  -- Invisible part, just particle host
    westFire.Parent = workspace
    
    -- Fire particle emitter
    local fireEmitter = Instance.new("ParticleEmitter")
    fireEmitter.Texture = "rbxasset://textures/particles/fire_main.dds"  
    fireEmitter.Rate = 50
    fireEmitter.Lifetime = NumberRange.new(1, 3)
    fireEmitter.Speed = NumberRange.new(2, 5)
    fireEmitter.Color = ColorSequence.new(Color3.fromRGB(255, 100, 0))  -- Orange fire
    fireEmitter.Parent = westFire
    
    -- East boundary fire (similar pattern)
    local eastFire = Instance.new("Part")
    eastFire.Name = "ZoneFire_East"
    -- Similar setup to westFire but positioned at zoneBounds.eastX
    
    -- Store in fireEffects table for cleanup
    table.insert(fireEffects, westFire)
    table.insert(fireEffects, eastFire)
end

-- Update visual effects when zone shrinks
function updateZoneVisuals()
    local bounds = getCurrentZoneBounds()
    createFireEffects(bounds)
end
```

- Fire effects move with shrinking boundaries each phase

- Use Config canyon boundary constants for positioning

- Ground-level fire wall appearance (not floating)
