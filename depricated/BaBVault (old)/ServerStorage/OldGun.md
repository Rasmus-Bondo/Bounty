# OldGun

Deprecated backup of an earlier version of the BanditGun tool. Contains the same script structure (GunServer, GunClient, RevolverGuiClient) but with an older codebase (~640 lines in GunServer vs ~656 in current). Kept for reference but not used in gameplay.

**Path:** `game.ServerStorage.OldGun`
**Type:** Folder

## Contents

- **BanditGun** (Tool) — older revolver with Handle, MuzzleAttachment, FireSound, ReloadSound, and the three scripts

## Notes

- The current [[BanditGun Tool]] has additional features not present here (e.g., animated revolver model with RevolverTest, reload body animations via [[BanditGun LocalScript]])
- This folder can likely be safely deleted once the current gun is fully stable
