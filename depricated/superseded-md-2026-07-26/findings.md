# Findings: Vesper Implementation (+ Bram addendum at bottom)

## Big architecture facts (Phase 1)
- **CardsServer is a self-running Script** under `ServerScriptService.Hunters.FortunaServer` — Main.lua does NOT wire Fortuna. → Vesper server entry = self-running Script `SunspikeModule` under `ServerScriptService.Hunters.VesperServer`, no Main edit.
- **HunterFirstPersonClient** (`StarterPlayerScripts`) is a generic arms-only first-person fallback for ANY hero that isn't Dust/Fortuna: clones `ReplicatedStorage.RevolverDefaultViewmodel.ArmsViewModel` (arms only, weapon hidden), locks first-person camera + mouse during rounds, does sway/bob, runs AimAssistController (touch-only). → **Vesper needs NO dedicated viewmodel client**; manifest omits `Client.ViewmodelTemplate`. Deviation from guide (guide planned VesperDefaultViewmodel) — fallback is the codebase's own convention "until each hero gets a dedicated viewmodel".
- **HeroSelectionService.normalizeHeroName passes unknown names through** — "Vesper" in teleportData → category="Vesper", `SelectedHero="Vesper"` attribute. No server edit needed for gating.
- **SkinService falls back to `player:LoadCharacter()`** when no character model exists for the hero → Vesper players spawn as their Roblox avatar until a VesperDefault model is made (art follow-up).
- **MovementChecker skip conditions**: `player:GetAttribute("ACImmune")`, `character:GetAttribute("IsDashing")`, `FortunaDashGraceUntil` (time value, `tick()`-based), `UltimateActive` (speed checks). → Grapple: set `FortunaDashGraceUntil`-style grace via **new `GrappleGraceUntil` attribute — requires small MovementChecker edit** (2 places, lines ~73 & ~156). Alternative: reuse IsDashing (rejected: DashDust VFX + JumpImpact key off it).
- **Dash movement is CLIENT-owned** (RevolverDashService server side only validates cooldown, plays anim, sets IsDashing attr; comment says client-owned avoids server correction). → Grapple pull should also be client-executed: server validates ray + cooldown, replies with anchor point via GrappleFX; caster client does the velocity pull.

## RevolverModule fire pattern (SunspikeModule mirrors)
- `FireBullet(player, cameraOrigin, cameraDirection, muzzlePosition)` → validate hero → roundActive → SpawnProtectionService.onAttack → GetCharacterHumanoidRootHead → validateFireInputs (typeof Vector3, dir magnitude) → cooldown via os.clock table → RegisterShotFired → clamp rayOrigin to ≤14 from head, muzzle ≤16 → resolveShot: lagComp:Raycast → workspace:Raycast (Exclude: character + rewindFolder + HealthPack tagged, IgnoreWater) → hitForgiveness:FindForgivenHumanoid → miss. Each hit branch: oldHealth, distance, damageService:ApplyDamage(char,hum,isHeadshot,distance) → runHitPipeline. Then LastDamager attr, impact FX for world hits, replicate tracer to other players (muzzlePos, hitPos).
- RevolverLagCompensation.new({RunService, CharacterUtil, Enabled, Range, HistoryRecordRate, MaxHistoryTime, MaxRewindTime, ExtraRewindOffset, TrackedBodyParts}) + :Start(); `.RewindHitboxFolder` used in ray excludes. RevolverHitForgiveness.new({CharacterUtil, Enabled, Radius, MaxDistance}) — both hero-agnostic, take config → **share directly for Vesper**.
- RevolverDamageService.new: {Damage, HeadshotDamage, BodyMinDamage, HeadshotMinDamage, FalloffStartDistance, FalloffEndDistance}; GetDamageForDistance lerps; ApplyDamage returns (didKill, damageDealt). SunspikeDamageService = same + headshot bonus multiplier param.
- Cooldown check tolerance: RevolverModule uses exact `now - last < cooldown` — Vesper 1.8s same pattern (add small 0.05 tolerance? Dust doesn't; match Dust exactly, client enforces its own).

## Vesper-specific decisions locked
- Manifest omits ViewmodelTemplate + Remotes.Bindables; ClientEvents: AmmoChanged, Reloaded, GrappleCooldownStarted, PinningCooldownStarted, UltimateCooldownStarted, UltimateChargeChanged, ScopeChanged, FireRequested, GrappleRequested, PinningRequested, UltimateRequested, ReloadRequested.
- Grapple: server validates (raycast 125, Exclude character+WallMap+rewind hitboxes; whiff→no cooldown, GrappleFX "Miss"), sets GrappleGraceUntil attr + IsGrappling attr, fires GrappleFX to all (kind, player, startPos, anchorPos). Caster client pulls via per-Heartbeat AssemblyLinearVelocity toward anchor (speed = dist/TravelTime capped), arrival 4 studs / timeout 1.2s. Other clients draw rope beam.
- Pinning: server-simulated ballistic projectile (Heartbeat integration, gravity, raycast per step, 3s max flight), lands → GetPartBoundsInRadius(25) → enemy humanoids → VesperStatusEffects:ApplySlow + :ApplyMark (server WalkSpeed enforcement loop + Marked attr) → PinningImpactFX to all (landPos, hitCharacters list) — Vesper's own client renders AlwaysOnTop Highlights on hit characters for MarkDuration (local-only reveal), everyone renders impact sphere VFX.
- Starfall: UltimateRequest (full charge → Set 0, state {shots=3, expires=now+12}), UltimateState("Start", shotCount, window) to caster; client sets local ammo=max(ammo,3). UltimateShotRequest same validation as FireBullet but resolves via pierce: iterate HunterCharacterUtil.GetHumanoidModels() within 400, in front, perpendicular distance to ray ≤1.3 → ring damage 100/75/50, each through hitPipeline SourceType="Ultimate". Cadence shares fireCooldowns. ChargeBlockPredicate blocks charge while starfall active. UltimateState("End") on exhaust/expiry.
- Deadeye: scopeState[player]={scoped, since}; ScopeStateChanged(bool) remote sets/clears; any successful fire resets `since=now`. Headshot bonus = MaxBonus * clamp((now-since)/RampTime,0,1) applied in SunspikeDamageService as multiplier after falloff. Server also sets WalkSpeed 6/16 on scope change (+ VesperStatusEffects slow interplay: scope speed × (1-slow) if slowed).

# Bram addendum (2026-07-05, live-source verified)

## Confirmed infra facts
- `HunterStatusEffects` @ RS.Hunters.Shared — instance-based: `.new(config)`, `:ApplySlow(character, pct, duration)` (refresh+max, never compounds), `:ApplyMark`, `:IsSlowed`, `:ClearCharacter`, `:Destroy`. Each hunter makes own instance.
- `RevolverDashService` @ RS.Revolver.Modules.RevolverServer — SERVER validator: `.new({Cooldown,Time,DashStartSpeed,DashPeakSpeed,DashEndSpeed,DashRampUpFraction,AnimationId,...})`, `:DoDash(player, moveDir)` → bool (cooldown via tick() in self.Cooldowns[player], sets IsDashing attr for Time, plays anim, AutoRotate juggle, flattens Y, blocks IsUsingHighNoon). Movement is CLIENT-owned.
- Client dash execution = CardsClient runAbility1Dash pattern: LinearVelocity constraint (Vector mode, MaxForce inf, world-relative) on CharacterRoot + Heartbeat speed-curve update + collision-scale pre-raycast (expectedDist, buffer 3.5, minScale 0.12) + momentum bleed 0.75 on cleanup. Fire request BEFORE local velocity (anti-cheat ordering). Dust defaults 28/72/22 ramp 0.22.
- MovementChecker: MAX_HORIZONTAL_SPEED=40 (instant vel, every 0.5s), MAX_HORIZONTAL_DELTA=70 (positional), skips when ACImmune | IsDashing | FortunaDashGraceUntil | GrappleGraceUntil (2 sites: runChecks ~L73-75, onStateChanged ~L157-159). `UltimateActive` char attr skips horizontal-speed + airborne checks (not the delta check). Violations: 5 → kick. → Knockback 50 studs/s needs new `KnockbackGraceUntil` attr in both sites (GrappleGraceUntil precedent).
- HunterHitPipeline:Register auto-awards charge via ChargeService:AwardHit(SourceType); unknown/absent source = silent no-award; didKill uses source.Kill. Also sets LastDamager, flash, damage direction, health reveal, killfeed, killcam, RoundStats. → per-shot charge rule: primary target SourceType="Basic", extra targets "BasicSecondary" {Hit=0,Headshot=0,Kill=5}; abilities "Ability" {0,0,5}.
- UltimateChargeService: Set() clamps + fires ChargeUpdateRemote (skipped while blocked); AwardHit ignores non-Player attackers; BlockPredicate blocks passive+hit accrual. Charge resets on round start.
- TakeDamage sites for Last Call 50% reduction (attr `DamageReductionPercent` on victim character): RevolverDamageService:ApplyDamage (L44-47), SunspikeDamageService:ApplyDamage (L50-57), HighNoonDamage:Apply (L172-178, apply AFTER execute-threshold branch), CardsServer.damageHumanoid (L207-208, var `damage`, char `targetCharacter`), StarfallSightModule.resolvePiercingShot (L108-110, var `ringDamage`, char `model`). ZoneService deliberately NOT reduced (zone pressure ignores ult) — document.
- Ungated per-hero client precedent: `FortunaCardsWorldVisibilityClient` top-level in SPS (no runtime gate, attribute-driven). → `BramWorldFXClient` (top-level SPS LocalScript): BreachChargeFX → victim self-knockback (client-owned physics; server can only push bots) + impact VFX for all; ShrapnelShellFX → explosion VFX for all.
- Gated-client convention: tracers/FX handlers inside hero-gated scripts are only seen by same-hero players (Vesper shipped this way) — keep ReplicateShot in gated GrudgekeeperClient.
- GUI: VesperHunterGuiClient is direct template. cooldownVisuals tokened → re-firing CooldownStarted(remaining) restarts cleanly (used for ult refresh/-1s refunds). OTHER_HUNTER_GUI_NAMES lists need "BramGameGui" added in other heroes' GUI clients.
- StarfallSightModule = ultimate template: charge gate (Get < MaxCharge → return), Set 0, token + task.delay expiry, UltimateState FireClient Start/End, PlayerRemoving cleanup.
- PinningRoundService = AoE template: GetHumanoidModels + root-distance + IsEnemy + alive filter, ApplySlow per victim, FX FireAllClients.

## Bram design decisions locked
- 12 scripts: RS Manifest+GrudgekeeperConfig; SSS GrudgekeeperModule(Script)+GrudgekeeperDamageService+BreachChargeService+ShrapnelShellService+LastCallModule; SPS.Bram GrudgekeeperClient+BramHunterGuiClient; SPS BramWorldFXClient (ungated).
- Pellets: 8 dirs server-generated, θ=halfAngle*sqrt(rand), φ=rand*2π via CFrame.lookAt basis. Per pellet: lagComp:Raycast → workspace:Raycast (NO forgiveness sphere — guide-sanctioned perf cut). Damage accumulated per target, ONE TakeDamage + ONE Register per target; primary (max damage) = "Basic", rest "BasicSecondary". IsHeadshot = any head pellet on that target.
- Breach: server BreachChargeService wraps RevolverDashService.new(30/85/24, ramp 0.22, Time 0.4, Cooldown 6) + Heartbeat sweep (HitboxRadius 6, debounce set); victims: damage 15 via injected ApplyAbilityDamage, knockDir horizontal outward; player victims → KnockbackGraceUntil attr + FX remote (self-knockback client-side), bots → server AssemblyLinearVelocity. Client: own LinearVelocity curve dash; direction = MoveDirection or camera-forward fallback (mobile parity).
- Shrapnel: hitscan (origin head-clamped), Range 100, landing → inner 5.4/50dmg/30% slow, outer 12.2/25/15%, 2s, exclude shooter, IsEnemy filter; own cooldown table 8s; does NOT touch mag/reload.
- Last Call: attrs UltimateActive + DamageReductionPercent=0.5; WalkSpeed 16→20; ResetCooldown both abilities; fire cooldown 0.5→0.25 (server isFireReady branches on IsActive), reload 1→0.5 (client); lifesteal 25% of actual dealt (all Bram damage paths, clamp MaxHealth); -1s both cooldowns per landed BASIC shot (≥1 pellet) → AbilityCooldownsReduced remote (caster) with remaining values; ChargeBlockPredicate = LastCallModule.IsActive; 10s token expiry + death + round-end teardown.
- Remotes: FireShotgun, ReplicateShot(muzzle, endPositions[]), BreachChargeRequest, BreachChargeFX, ShrapnelShellRequest, ShrapnelShellFX, UltimateRequest, UltimateState, UltimateChargeUpdate, AbilityCooldownsReduced.
- ClientEvents: AmmoChanged, Reloaded, BreachChargeCooldownStarted, ShrapnelShellCooldownStarted, UltimateCooldownStarted, UltimateChargeChanged, FireRequested, BreachChargeRequested, ShrapnelShellRequested, UltimateRequested, ReloadRequested.
- Keybinds: Q=Breach, E=Shrapnel, F=Ult, R=reload, LMB/mobile FIRE button. Health 225 via CharacterAdded (Vesper pattern). No viewmodel (HunterFirstPersonClient fallback), no character model (LoadCharacter fallback), no HeroSelectionService entry needed.
- HighNoon execute vs 50% DR: reduction applies after execute branch (all incoming damage) — can survive an execute during Last Call; flagged in handoff.
